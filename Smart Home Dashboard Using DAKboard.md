## Setup Guide  
1. **Flash OS**: Use [DAKboard OS Image](https://dakboard.com/site/os).  
2. **Mount Display**: Recessed in-wall installation ([This Old House Guide](https://www.thisoldhouse.com/)).  
3. **Integrations**:  
   - Google Calendar  
   - Todoist  
   - Weather Underground API
